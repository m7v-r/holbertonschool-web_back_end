# NodeJS Basics

This project covers the fundamentals of Node.js, including executing scripts, using core modules, creating HTTP servers using native modules and Express.js, and working with Babel and ESLint.

## Learning Objectives
- Run JavaScript using NodeJS
- Use NodeJS modules
- Read files using Node.js filesystem (`fs`) module
- Use `process` to access command line arguments and environment variables
- Create an HTTP server using Node.js native `http` module
- Create an HTTP server using Express.js
- Use Babel with Node.js
- Develop faster using Nodemon

## Requirements
- Node.js (version 20.x.x)
- Ubuntu 20.04 LTS environment
- Code tested using Mocha & Jest
- Code linted using ESLint
